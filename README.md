# SMART TALK AI (AI Virtual Assistant)

An advanced full-stack AI Assistant built with the MERN stack that can talk, think, and remember like a real assistant, Powered by Gemini AI and the Web Speech API

# Tech stack

React  
Node.js  
MongoDB  
Gemini AI
JWT + bcrypt (Authentication)  
Multer + Cloudinary (Image Upload)

# Deployment

Backend: Render

Database: MongoDB Atlas

Media Storage: Cloudinary

# Run

Run backend

cd backend 
npm run dev 

Run frontend

cd  frontend
npm run dev

# working

1.First, enter the name and required details.

2.Start the interaction by calling the assistant’s name.

3.Speak slowly so that it can process your words correctly.

4.Use a somewhat louder voice for better recognition.

5.The assistant will then understand your command clearly.

6.It will respond and perform the task as instructed.
